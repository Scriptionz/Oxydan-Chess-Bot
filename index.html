🧠 Deep Technical Analysis

1. The Neural Network (NNUE) Implementation

Unlike traditional engines that rely on hand-crafted evaluation terms, Oxydan's core employs Neural Network evaluation (NNUE). This allows the engine to perceive complex positional advantages that cannot be manually encoded. The network has been trained on billions of positions, producing 2900+ ELO performance on standard hardware.

2. Opening Theory: The Cerebellum Advantage

Oxydan uses the Cerebellum3Merge opening book — a curated library where moves are weighted by winning probability. By offloading the opening phase to a pre-compiled library, the engine conserves CPU cycles for middle-game calculations. An anti-repetition system ensures Oxydan does not play the same opening line twice within 10 consecutive games.

3. Infrastructure: Cloud-Powered Logic

Running on GitHub Actions infrastructure with a rolling 6-hour cycle, Oxydan benefits from high-speed CPU and low-latency API connections. The system automatically stops accepting new games 15 minutes before the cycle ends, then relaunches seamlessly. Exponential backoff handles Lichess rate limits (HTTP 429) without dropping connections.

4. Endgame Perfection

When the board reaches 7 pieces or fewer, Oxydan stops calculating and starts knowing. By probing Syzygy Tablebases via the Lichess API, the engine finds the mathematically optimal path to victory or draw with zero margin for error.

5. Time Management

Oxydan's dynamic time algorithm adjusts per move based on game phase (opening / middlegame / endgame), board complexity (legal move count), and panic thresholds. Move overhead is kept at 100ms to prevent time losses in fast time controls, while a ±12% random variation makes the bot's timing less predictable.
